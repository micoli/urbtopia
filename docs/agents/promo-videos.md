# Promo videos

`node scripts/promo/cli.ts <scenario> [--fresh] [--scene=<name>]` films `scripts/promo/scenarios/<scenario>.promo.ts` against the running dev server (`PROMO_URL`, default `http://127.0.0.1:5175`) and writes `tmp/promo/<scenario>.mp4`. `npm run promo -- <scenario>` does the same.

- A scene is `scene(name, { state, language, time, viewport, ui, hideTaxBadges }, async (stage) => { ... })`. `state` is a save file path from the repository root (`saves/ideal-city.json`). `hideTaxBadges: true` hides the tax bubbles over the buildings (the `showTaxBadges` preference).
- Verbs of `Stage`: `wait`, `caption`, `hideCaption`, `move`, `click`, `point(target)`, `circle(target)` (the cursor rests on, or loops around, a widget to show it), `clickAt`, `clickTile(x, y)`, `type`, `drag`, `zoom`, `flyTo(x, z, zoom, seconds)`, `timelapse({ hours, seconds })`, `skip(hours)`, `send(command)`, `pinCycleHour`.
- Scenes are cached in `tmp/promo/<scenario>/` by hash of the scene, its state and `scripts/promo/*.ts`; `--fresh` films again. `--scene=<name>` films one scene and does not assemble. `--fast` runs the scenario to test it (no pause, no video, no assembly, `stage.cinematic` blocks skipped, `stage.check` kept); `PROMO_TRACE=1` prints the time of each verb.
- `?promo` (dev only) hides the banners, hints, explanatory notes, tooltips and guided demonstrations, and the DEV button, shows a fake cursor and the captions, and lights the map as Daytime outside a time-lapse.
- The interface is hidden by default. A scene lists the parts it shows (`ui: ['hud']`, then `stage.ui('hud', 'build')` as the action moves); the main menu (the dock buttons) is never hidden: `hud` (Urbs, clock, stats), `camera` (undo, redo, layout buttons), `build` (Build menu and confirm pad), `selection` (the floating bar of a selected building), `panel` (the side panel). A part a click needs must be listed before the click.
- The game is filmed in layout C (side panel), with the pedestrians drawn as the players' avatars (`pedestrianModel: 'avatar'`), never as stick figures. The Build menu row opens the Codex on its name; a building is chosen with the picture/price button (`.flyout-row .flyout-info`). A click on a free tile places the building at once, after the mouse has moved over it.
- Interiors: `scripts/promo/interior.ts` has `openInteriorBuild(stage)` and `placeFixture(stage, { section, fixture, cell, rotations })`. A row of a build menu carries `data-choice="<id>"` (the Fixture id), whatever the language; the interior menu closes after each placement, `placeFixture` reopens it. `tileToScreen` and `clickTile` use the cells of the open interior. `scripts/promo/states/early-city.json` (60 Citizens, 6000 U) is built by `node scripts/promo/buildEarlyCity.ts`. A scene that fails leaves `tmp/promo/<scenario>/<scene>.error.png`.
- The `promo-video` skill drives all this from a scenario described by the user.
