# 21: Unlocks by total Citizens

**What to build:** New Materials and Goods open as the city's total Citizens grow, completing the six Goods chain.

**Blocked by:** 20

**Status:** ready-for-agent

- [x] Start open: Wood, Stone, Planks, Bricks and all base buildings
- [x] 30 Citizens unlocks Clay and Tiles; 80 unlocks Metal and Tools; 200 unlocks Silicon, Glass and Circuits
- [x] All Materials and recipes of the economy table work (Clay 4 min, Metal 8 min, Silicon 16 min; Tiles, Tools, Glass, Circuits recipes and values)
- [x] Total Citizens is derived from state, nothing extra saved
- [x] HUD shows only the next threshold, for example "18/30 Citizens: Clay, Tiles"
- [x] Locked items are not queueable and show their threshold
- [x] No end screen; the game stays a sandbox after 200 Citizens
- [x] Core tests cover each threshold
