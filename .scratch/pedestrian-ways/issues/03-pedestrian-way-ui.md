# Build tools, costs and map presentation

Status: claimed
Blocked by: 01

## What to build

Expose Pedestrian way build, upgrade and demolition tools in the Road build section, available from the start, and render the network on the map.

## Acceptance criteria

- [x] Player can draw a Pedestrian way with the existing drag-to-build interaction and choose upgrade/demolition tools.
- [x] Build-menu construction and upgrade costs show 90% of corresponding Road costs.
- [x] A placed Pedestrian way is visually distinct from a Road and updates its visual connections at endpoints and between adjacent Pedestrian way tiles.
- [x] French and English UI strings are present.
- [ ] Rendering is checked in the development scene.
